Supported Models

Every model below ships pre-exported in the models registry and downloads on first use. Backends: XNNPACK (CPU, iOS and Android), Core ML and MLX (iOS), Vulkan (Android GPU); DEFAULT picks the fastest one the device can run. Any other ExecuTorch .pte can be loaded too, see Exporting Custom Models.
